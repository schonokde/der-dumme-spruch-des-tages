# Der dumme Spruch des Tages – Website

Eine statische Website, die auf GitHub Pages veröffentlicht werden kann.

## Veröffentlichung über GitHub Pages
1. Lade alle Dateien aus diesem Ordner in das Hauptverzeichnis deines GitHub-Repositorys hoch.
2. Öffne im Repository **Settings** → **Pages**.
3. Unter **Build and deployment** wähle **Deploy from a branch**.
4. Wähle Branch **main** und Ordner **/(root)**, dann **Save**.
5. Warte ein paar Minuten. GitHub zeigt dort die veröffentlichte Website-Adresse an.

Die Website speichert Favoriten im Browser dieses Geräts. Ein Teil der Spruch-Zuschreibungen ist absichtlich als zu prüfen gekennzeichnet; bitte nicht als verifizierte Zitate behandeln.
